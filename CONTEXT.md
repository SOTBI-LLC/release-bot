# Telegram-оповещения Grafana

Уведомления о состоянии сервисов из Grafana доставляются в выделенный Telegram-чат.

## Language

**Contact point**:
Настройка Grafana, определяющая канал доставки уведомлений об алертах.
_Avoid_: правило алерта, Telegram-бот

**Notification policy**:
Правило маршрутизации, выбирающее contact point для уведомлений по признакам алертов.
_Avoid_: правило алерта, contact point

**Выбранные алерты**:
Алерты, уведомления которых направляются только через бота оповещений. Существующая маршрутизация остальных алертов сохраняется.

**Уведомление**:
Сводка группы алертов Grafana, доставляемая в чат оповещений. В одной сводке могут присутствовать алерты разных состояний.

**Firing**:
Состояние алерта, который Grafana считает сработавшим.

**Resolved**:
Состояние алерта, который Grafana больше не считает firing; само по себе не доказывает восстановление сервиса.
_Avoid_: проблема устранена, сервис восстановлен

**Принятое уведомление**:
Уведомление, сохранённое ботом для последующей доставки в чат; это ещё не подтверждение отправки в Telegram.
_Avoid_: доставленное уведомление

**Доставленное уведомление**:
Уведомление, отправку всех частей которого подтвердил Telegram. Это не подтверждение прочтения сообщения человеком.

**Окончательная ошибка доставки**:
Неуспешная доставка, автоматические попытки которой окончательно прекращены; её причина остаётся доступной для разбора.

**Бот оповещений**:
Отдельный Telegram-бот, доставляющий уведомления Grafana в чат оповещений.
_Avoid_: releasebot, contact point

**Чат оповещений**:
Единственный Telegram-чат, выбранный получателем уведомлений этого бота.
_Avoid_: пользователь-получатель, contact point

**Задержанное уведомление**:
Уведомление о более раннем состоянии алертов, доставленное после ожидания; время доставки отличается от времени события.
_Avoid_: новый инцидент
